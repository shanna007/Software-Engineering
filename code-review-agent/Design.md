## 一、项目目标
实现一个具备基础能力的代码审查Agent，掌握Agent开发核心技术：LLM调用、Prompt工程、工具集成、Agent循环、上下文记忆与错误处理。

## 二、技术选型
| 模块 | 选型 | 选型理由 |
|------|------|----------|
| 开发语言 | Python 3.10+ | Agent生态成熟，代码处理库丰富 |
| Agent框架 | LangChain | 业界主流框架，内置工具、记忆、Agent模式封装 |
| LLM | OpenAI兼容模型 | 通用性强，可无缝切换多种大模型 |
| 交互方式 | 命令行CLI | 快速验证核心功能，符合项目要求 |

## 三、整体架构
采用单Agent + ReAct模式架构，核心流程：
```
用户输入 → Agent 推理 → 工具调用 → LLM 分析 → 结果输出
↑                           ↓
└──────── 上下文记忆 ────────┘
```

## 四、核心模块说明
1. **配置模块**：统一管理LLM与Agent参数，敏感信息通过环境变量加载
2. **Prompt模块**：定义专家角色、审查维度与输出格式，控制Agent行为
3. **工具模块**：实现文件读取工具，包含路径安全校验与多编码兼容
4. **Agent核心**：基于ReAct模式实现推理-行动循环，内置记忆与错误重试
5. **交互模块**：命令行入口，处理用户输入与异常

## 五、关键技术点
1. **Agent循环**：ReAct模式自动完成思考-行动-观察的迭代
2. **工具集成**：基于LangChain Tool规范自定义工具，Agent可自动调用
3. **上下文记忆**：程序内部维护 messages 消息列表，复用 LangGraph ReAct Agent 原生消息上下文，实现多轮对话记忆
